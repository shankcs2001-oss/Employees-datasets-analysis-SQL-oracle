# Employees-datasets-analysis-SQL-oracle

**Project Overview**

This project focuses on analyzing employee data using Oracle SQL to practice database querying and derive insights about employee salaries, departments, job roles, and demographics.

**Tools Used**

Oracle SQL
SQL Developer or another Oracle-compatible SQL editor

**SQL Concepts**

Filtering and Quering.
Aggregate functions.
GROUP BY and HAVING.
Joins and table aliases.
Subqueries and correlated subqueries.
Window functions.
CTE.

**Analysis Objectives**

1.Identify the highest-paid employees.
2.Compare average salaries across departments. 
3.Find employees earning above their department's average salary.
4.Explore employee distribution by department, job role, and location.
5.Find expense on employee across different city-wise.

**Key Learnings**

This project helps develop practical SQL skills, understand employee datasets, and solve data analysis questions using Oracle SQL.
